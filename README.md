# sjcoders-git-training--shweta-

Git \& GitHub fundamentals training repository for SJ Coders Software internship, covering basic Git commands, branching, commits, push/pull, and Pull Requests.## Day 3 - Employee Management System



\### Architecture

The application follows a layered architecture:



Frontend (HTML, CSS, Bootstrap, JavaScript)

→ Controller

→ Service

→ Repository

→ MySQL Database



\### API Endpoints

\- POST /api/employees - Create a new employee

\- GET /api/employees - Get all employees

\- GET /api/employees/{id} - Get employee by ID

\- GET /api/employees/search?query=value - Search employees by name or department



\### Database

MySQL is used as the database.



Database name: sjcoders\_training



\### How to Run the Backend

1\. Open Git Bash.

2\. Go to:

&#x20;  day-03-employee-management/backend/training

3\. Set the DB\_PASSWORD environment variable with your local MySQL password.

4\. Run:

&#x20;  ./mvnw spring-boot:run

5\. Backend runs on:

&#x20;  http://localhost:8080



\### How to Run the Frontend

1\. Go to:

&#x20;  day-03-employee-management/frontend

2\. Open index.html in a web browser.

3\. Use the Employee Registration Form to add employees.

4\. Use the search box to search by employee name or department.



\### Technologies Used

\- Java

\- Spring Boot

\- Spring Data JPA

\- MySQL

\- HTML

\- CSS

\- Bootstrap

\- JavaScript

\- Postman
